# Deviations from the C coding standard

Places where a rule of the [C coding standard](../../docs/coding-standard.md)
is not met, one entry per place, in the format the standard's "Deviations"
section defines. Mutable static storage is recorded separately, in
[`static-storage-allowlist.txt`](static-storage-allowlist.txt).

No deviations are recorded.
